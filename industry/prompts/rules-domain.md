
【安防行业术语与命名规则 — 本平台是视频监控与安防行业内容，严格遵守】

1. 歧义默认值：以下词在中文里有安防行业之外的常见含义，**一律按安防/视频行业含义理解与翻译**：
   - IPC / IP Camera = 网络摄像机（绝不译"IP 地址摄像机"）
   - NVR = 网络硬盘录像机；DVR = 数字硬盘录像机；XVR = 混合型录像机
   - PTZ = 云台（Pan-Tilt-Zoom，保留缩写或写"云台摄像机"）
   - VMS = 视频管理系统（不是"版本管理系统"）
   - CMS = 中央管理平台；Platform = 平台软件
   - Channel = 通道（设备接入路数，不是"频道"/"渠道"）
   - Stream = 码流（主码流/子码流/第三码流，不是"流媒体平台"）
   - Bitrate = 码率；Frame rate / FPS = 帧率；Resolution = 分辨率
   - Encoding = 编码（H.264/H.265/H.266 指视频编码标准，不是"字符编码"）
   - Codec = 编解码器
   - Low light = 低照度（不是"低光量"）；Starlight = 星光级（低照度等级，不是"星光"）
   - WDR = 宽动态；BLC = 背光补偿；HLC = 强光抑制；3DNR = 三维降噪
   - Analytics / IVA = 智能分析（视频分析，不是"数据分析部门"）
   - Structured data / Video structuring = 视频结构化
   - Perimeter / Perimeter protection = 周界 / 周界防范
   - Access control = 门禁；Intercom = 对讲；可视对讲 = video intercom
   - Alarm / Intrusion = 报警 / 入侵报警；Detector = 探测器
   - Radar = 雷达（毫米波雷达 mmWave radar）；Thermal = 热成像
   - Fusion = 融合（雷视融合、热成像与可见光融合）
   - Edge = 边缘（边缘计算/端侧，不是"刀刃"）
   - Firmware = 固件；Upgrade = 升级（固件升级）
   - ONVIF = 设备互联标准（保留英文，不译）
   - GB/T 28181 = 国标联网协议（写作 GB/T 28181，不要写成 "GB28181 标准协议"以外的译名）
   - PoE = 以太网供电；Power over Ethernet 保留
   - Face recognition = 人脸识别；License plate / ANPR / LPR = 车牌识别
   - Behavior analysis = 行为分析；People counting = 客流统计
   - AI camera / smart camera = AI 摄像机 / 智能摄像机
